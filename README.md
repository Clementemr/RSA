# RSA

A fully functional implementation of 2048-bit RSA encryption. The message is written in the plaintext file and turned into encrypted blocks which can then be decrypted by the same program. The key generation function generates public and private keys, then writes that information to the n (public), e (public), and d (private) key files accordingly.
